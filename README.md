# AI 챔피언 블루 이론 학습실

AI 챔피언 블루 시험 준비를 위한 개인 학습 페이지입니다.

- 개념 요약과 암기 카드
- 예상 문제 은행과 선택지별 해설
- 오답 복습과 모의 연습

공식 시험 사이트가 아니며, 예상 문제의 실제 출제를 보장하지 않습니다.
출처는 학습 페이지에 표시되어 있습니다. 원본 가이드와 PDF 자료는 이 저장소에 포함하지 않습니다.
학습 기록은 사용하는 브라우저의 로컬 저장소에 보관됩니다.

`index.html`을 열거나 저장소의 GitHub Pages 주소에서 사용할 수 있습니다.
